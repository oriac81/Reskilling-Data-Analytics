This repository contains the deliverables and projects completed during the **IT Academy Data Analytics Reskilling program**. It showcases a progressive learning path from foundational SQL to advanced analytics with Python and interactive dashboards in Power BI.

## 🎯 Overview

The work is organized by sprints, covering:
- **SQL**: Database queries, data extraction, and manipulation.
- **Python (Jupyter Notebooks)**: Data analysis, visualization, and introductory machine learning.
- **Power BI**: Interactive dashboards for business intelligence and storytelling.
- **Reports (PDF)**: Summaries, insights, and project presentations.

## 🛠️ Technologies Used

- **SQL** (for data querying and transformation)
- **Python** (Pandas, Matplotlib, Seaborn) - in Jupyter Notebooks (`.ipynb`)
- **Power BI** (`.pbix` files with interactive dashboards)
- **Markdown** (for documentation)
